Cómo usar Mixeo

  • Curvas: toca dentro del recuadro para añadir un punto; arrástralo para moverlo. Mitad superior = pista saliente (A), inferior = entrante (B).
  • Punto seleccionado: elige la forma del tramo (suave, lineal, rápida, lenta, escalón) o elimínalo. Doble toque también elimina.
  • Puntos de mezcla: arrastra el marcador en la miniatura de cada pista o usa ±beat / ±compás.
  • Regla superior: toca para saltar a ese instante.
  • Teclado: Espacio reproducir/parar · Supr borrar punto · Ctrl+Z / Ctrl+Shift+Z deshacer/rehacer · 1–8 cambiar de carril.
  • Armonizar: transpone la pista B al tono compatible más cercano (rueda Camelot).
